# テーマ: 消すときの会話(私とあなた)

データを消すときに気をつけたことを、私(男性の声)とあなた(AI。女性の声)の会話にしたもの。

気をつけること(会話の順):
1. 残すものを先に決める(使っているデータ)
2. 消す前にバックアップを取り、確認する
3. 消すものを言う。記録(履歴)は消さない
4. 一度にまとめて消す(失敗したら何も変わらない)
5. 消した数と、残った数を言う
6. 動くか確認する
7. 戻せるようにしておく(バックアップから戻せる)

英文とリンキングはコピペ用。

## 1. 私

JA
```
今使っているデータ以外を、全部消してください。
```

EN
```
Please delete all the data except the data we use now.
```

リンキング
```
プリーズ ディリートール ザ デイタ イクセプト ザ デイタ ウィ ユーズ ナウ
```

連結ポイント: delete all → ディリートール(連結)
