# テーマ: AI との仕事のやりとり(私とあなた)

`ja-en-linking.md` の文節(25 個)を、AI の相手との会話の中で使う形にしたもの。私(男性の声)と、あなた(AI。女性の声)が交互に話す。英文とリンキングはコピペ用。
