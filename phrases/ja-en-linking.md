# 日本語 / 英語 / リンキング 一覧

ローマ字で書いていた日本語を、英語とリンキングにした一覧。英文とリンキングはコピペ用。

## この一覧の決まり(元の文章を壊さない)

- この一覧が、元の文章(正)。**番号と英文は変えない**。直したいときは、新しい番号で末尾に足す。
- 会話(`talk-work-chat.md` など)は、この一覧から作った別のテーマ。会話を直しても、この一覧は変えない。
- ローマ字の日本語は、番号を続けて末尾に追記する(同じ内容は重複登録しない)。

## 26. study_english_repeat にある用語を english-app に反映したい(ローマ字: ./study_english_repeat ni aru yougo wo english-app ni haneisitai)

EN
```
I want to reflect the terms in XXX in YYY.
```

リンキング
```
アイ ウォントゥ リフレクト ザ ターンジン XXX イン YYY
```

連結ポイント: terms in → ターンジン(連結) / XXX = study_english_repeat、YYY = english-app

メモ: ~ni haneisitai(~に反映したい)は I want to reflect ... in ...。`ni` は場所によって in / to を使い分ける(例: 設計書に反映 = reflect it in the design doc / 全員に反映 = apply it to everyone)

## リンキング単語集

連結(子音+母音)
```
make it → メイキット
put it → プリット
Is it → イジット
memorize it → メモライジット
turn it into → ターニリントゥ
sentences I → センテンセザイ
if I → イファイ
point them out → ポイントゼマウト
use often → ユーゾフン
run it → ランニット
installed it → インストールディット
fixed it → フィクスティット
compressing it → コンプレッシンギット
commit it → コミティット
terms in → ターンジン
what's in → ワッツィン
added a → アディダ
in a → イナ
from about → フロマバウト
sound is → サウンディズ
volume is → ヴォリュミズ
sentences is → センテンセジズ
```

同化(t/d + y)
```
want you → ウォンチュ
```

フラップT
```
better → ベラー
it into → イリントゥ
so that I → ソウザライ
```

脱落
```
current sentence → カーレンセンテンス
must be → マスビー
```

弱形(of / and / the)
```
part of → パートブ
each of → イーチョブ
copy and paste → コピーアンペイスト
the English → ジ イングリッシュ
```
