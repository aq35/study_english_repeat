# 日本語 / 英語 / リンキング 一覧

ローマ字で書いていた日本語を、英語とリンキングにした一覧。英文とリンキングはコピペ用。

## 1. 保存してほしい

EN
```
I want you to save this.
```

リンキング
```
アイ ウォンチュ トゥ セイブ ディス
```

連結ポイント: want you → ウォンチュ(t+y が同化)

## 2. 英訳にする前に

EN
```
Before translating it into English,
```

リンキング
```
ビフォー トランスレイティンギリントゥ イングリッシュ
```

連結ポイント: it into → イリントゥ(フラップT)

## 3. 今の文章が

EN
```
the current sentence
```

リンキング
```
ザ カーレンセンテンス
```

連結ポイント: current sentence → カーレンセンテンス(t が脱落)

## 4. ~にして(例: 柔らかい表現にして)

EN
```
Please make it softer.
```

リンキング
```
プリーズ メイキット ソーファー
```

連結ポイント: make it → メイキット(連結)

## 5. ~にして(例: 表にして)

EN
```
Please turn it into a table.
```

リンキング
```
プリーズ ターニリントゥ ア テイブル
```

連結ポイント: turn it into → ターニリントゥ(連結 + フラップT)

## 6. 以下、よく使う文章です

EN
```
The following are sentences I use often.
```

リンキング
```
ザ フォロウィンガー センテンセザイ ユーゾフン
```

連結ポイント: following are → フォロウィンガー / sentences I → センテンセザイ / use often → ユーゾフン

## 7. コピペできること

EN
```
It must be copy-and-pasteable.
```

リンキング
```
イッ マスビー コピーアンペイスタブル
```

連結ポイント: must be → マスビー(t が脱落) / copy-and-paste → コピーアンペイスト(and が ン に弱化)

## 8. XXXの箇所のコードをRustで書いてください

EN
```
Please write the code for the XXX part in Rust.
```

リンキング
```
プリーズ ライト ザ コード フォー ザ XXX パート イン ラスト
```

連結ポイント: part in → パーティン は軽く繋ぐ

## 9. 箇所です(そのコードの場所のことです)

EN
```
I mean the part of the code.
```

リンキング
```
アイ ミーン ザ パートブ ザ コード
```

連結ポイント: part of → パートブ(of が ブ に弱化)

## 10. ~じゃなくて、~

EN
```
Not the linking, but the English sentences.
```

リンキング
```
ノット ザ リンキング バット ジ イングリッシュ センテンセズ
```

連結ポイント: the English → ジ イングリッシュ(母音の前の the は ジ)

## 11. 英文をコピペできるように

EN
```
so that I can copy and paste the English sentences
```

リンキング
```
ソウザライ キャン コピーアンペイスト ジ イングリッシュ センテンセズ
```

連結ポイント: so that I → ソウザライ(that の t がフラップ化)

## 12. それぞれほしい

EN
```
I want each of them.
```

リンキング
```
アイ ウォン イーチョブ ゼム
```

連結ポイント: each of → イーチョブ

## 13. また、説明してください

EN
```
Also, please explain.
```

リンキング
```
オールソウ プリーズ イクスプレイン
```

## 14. 一度に俯瞰できるように

EN
```
so that I can see everything at a glance
```

リンキング
```
ソウザライ キャン シー エブリシング アタグランス
```

連結ポイント: at a glance → アタグランス

## 15. ~にしましょう

EN
```
Let's make Rust the topic.
```

リンキング
```
レッツ メイク ラスト ザ トピック
```

## 16. 覚えたほうがいい？

EN
```
Is it better to memorize it?
```

リンキング
```
イジット ベラー トゥ メモライジット
```

連結ポイント: Is it → イジット / better → ベラー(フラップT) / memorize it → メモライジット

## 17. 推敲した文 / 柔らかい文

EN
```
the polished sentence / the softer sentence
```

リンキング
```
ザ ポリシュト センテンス / ザ ソーファー センテンス
```

## 18. 今まで使ったローマ字の日本語を洗い出してください

EN
```
Please list all the romaji Japanese I've used so far.
```

リンキング
```
プリーズ リスト オール ザ ローマジ ジャパニーズ アイヴ ユーズド ソウ ファー
```

## 19. この文章で、日本語・英語・リンキングのテキストを作成してください

EN
```
Please create a Japanese, English, and linking text from the above.
```

リンキング
```
プリーズ クリエイト ア ジャパニーズ イングリッシュ アンド リンキング テキスト フロム ジ アバブ
```

連結ポイント: from the → フロム ジ(母音の前)

## 20. 同じブランチに入れてください

EN
```
Please put it in the same branch.
```

リンキング
```
プリーズ プリット イン ザ セイム ブランチ
```

連結ポイント: put it → プリット(連結)

## 21. 今後のルールに、私がローマ字の日本語を使ったら、学習の教材にしてください

EN
```
From now on, if I use romaji Japanese, please turn it into study material.
```

リンキング
```
フロム ナウ オン イフアイ ユーズ ローマジ ジャパニーズ プリーズ ターニリントゥ スタディ マテリアル
```

連結ポイント: if I → イファイ(連結) / turn it into → ターニリントゥ

## 22. はい(お願いします)

EN
```
Yes, please go ahead.
```

リンキング
```
イェス プリーズ ゴウ アヘッド
```

## 23. そして、記憶してた文に一致する、または近い箇所があれば指摘してください

EN
```
If there are any parts that match or are close to the sentences I've memorized, please point them out.
```

リンキング
```
イフ ゼア アー エニー パーツ ザット マッチ オア アー クロウス トゥ ザ センテンセズ アイヴ メモライズド プリーズ ポイントゼマウト
```

連結ポイント: point them out → ポイントゼマウト(連結) / sentences I've → センテンセザイヴ

## 24. ローマ字の日本語が、英文と意味が一致する場合も同じ(一致とみなす)

EN
```
A romaji sentence whose meaning matches an English sentence counts as a match too.
```

リンキング
```
ア ローマジ センテンス フーズ ミーニング マッチズアン イングリッシュ センテンス カウンツァザ マッチ トゥー
```

連結ポイント: matches an → マッチズアン / counts as a → カウンツァザ

## 25. 終わったら、このブランチをマージしてください

EN
```
When you're done, please merge this branch.
```

リンキング
```
ウェン ユア ダン プリーズ マージ ディス ブランチ
```

連結ポイント: メモ: please do merge は強調(「ぜひ」)になる。普通は please merge でよい

## リンキング単語集

連結(子音+母音)
```
make it → メイキット
put it → プリット
Is it → イジット
memorize it → メモライジット
turn it into → ターニリントゥ
sentences I → センテンセザイ
if I → イファイ
point them out → ポイントゼマウト
use often → ユーゾフン
```

同化(t/d + y)
```
want you → ウォンチュ
```

フラップT
```
better → ベラー
it into → イリントゥ
so that I → ソウザライ
```

脱落
```
current sentence → カーレンセンテンス
must be → マスビー
```

弱形(of / and / the)
```
part of → パートブ
each of → イーチョブ
copy and paste → コピーアンペイスト
the English → ジ イングリッシュ
```
